# Security Policy

## Supported Versions

Currently, only the latest release of `UniFi.Network.Client` receives security updates. 

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in UniFi.NET (such as exposure of credentials, improper handling of auth tokens, etc.), please DO NOT report it by creating a public GitHub issue.

Instead, please send a private message/email to **security@danielvanginneken.nl**. 

We will acknowledge receipt of your vulnerability report as soon as possible, and strive to send you regular updates about our progress in fixing the vulnerability.
